# 南海トラフ 津波浸水3D 全国版（簡易可視化）使い方マニュアル

はじめて使う方向けの説明書です。専門知識は不要です。
画面に表示される文字（ボタン名・項目名）は、そのまま「」で示しています。

---

## 1. このアプリでできること

- 南海トラフ沿岸の**市区町村を選ぶ**と、内閣府が公表した**市町村別の津波高**（2025 年・2012 年）が表示され、地図がその市区町村へ移動します。
- 国土地理院の実際の標高データで作った**3Dの立体地図**の上に、公式の「重ねるハザードマップ（津波浸水想定）」を重ねて見られます（最初から ON）。
- 津波の高さスライダーを動かすと、地図上で**津波高より低い土地が青く**塗られ、即座に連動します（「津波高で試算」は初期ON。市区町村を選ぶとその範囲だけ、未選択なら全国一律の簡易試算）。公式想定と見比べられます。

> **必ずお読みください（免責）**
> 画面下にも表示されるとおり、本アプリは「**簡易可視化であり公式想定ではありません**」。
> 内閣府の津波高は**海岸線での最大値**で、内陸へ一律に当てはめると**過大にも過小にも**なります。
> 堤防・遡上・浸水深・時間変化は考慮していません。避難の判断は、必ず各自治体のハザードマップ
> （[ハザードマップポータルサイト](https://disaportal.gsi.go.jp/)）をご覧ください。

## 2. 起動方法（パソコンで動かす場合）

| 手順 | 操作 | 説明 |
|---|---|---|
| 1 | `npm install` | 最初の1回だけ。必要な部品を取り込みます（Node.js 20以上） |
| 2 | `npm run dev` | 開発用サーバーが起動します（既定ポートは **5291**） |
| 3 | ブラウザで開く | `http://localhost:5291/` を開きます |

- 同じWi-Fiにつないだスマホからは、パソコンのLAN IP（例 `http://192.168.x.x:5291/`）で開けます。
- 配布用に固めるときは `npm run build`（`dist/` に静的ファイルが出ます。`npm run preview` で `http://localhost:5295/`）。
- URL に `?m=市区町村コード` や `?h=津波高` を付けると、その状態で開きます（例 `?m=39201&h=10`＝高知市・10 m）。操作すると URL も自動で追従するので、そのままコピーして共有できます。

必要なブラウザ: **WebGL2** に対応したもの（iOS 15以降のSafari、最新のChrome / Edge / Firefox）。
非対応の場合は「このブラウザでは3D地図を表示できません」と表示されます。

## 4. ボトムシートの開閉

- シート上端の**細い横棒（ハンドル）をタップ**すると、閉じる／開くが切り替わります。要約行（市区町村名と津波高）をタップしても開きます。
- **上へスワイプ**で開く、**下へスワイプ**（シートを一番上までスクロールした状態）で閉じます。
- 閉じると、**要約行だけ**が残り地図が広く見えます。スケール・出典表示・読み取り表示もシートの上に移動します。

## 5. 基本操作は3ステップ

| ステップ | やること | 見るところ |
|---|---|---|
| 1. 市区町村を選ぶ | 「都道府県」→「市区町村」を選ぶか、「市区町村名で検索」に名前の一部を入れる（例「高知」） | 地図が移動し、津波高テーブルと要約行が更新。津波高は自動で「2025 最大」に |
| 2. 公式想定を見る | 「公式浸水想定（重ねるハザードマップ）」は最初から ON | 地図の色分け＝公式の浸水深。凡例はチェックの下に表示 |
| 3. 高さを変えて見比べる | スライダーやプリセットで津波高を変える | 地図の青塗りが即座に変わります（「津波高で試算」は初期ON）。選んだ市区町村の中で津波高より低い土地が青くなり、公式想定との違いを確認できます |

「この市町村へ移動」を押すと、いつでも選択中の市区町村の位置に戻れます。

### セミナーでの見せ方（追加機能）

| 操作 | 何が起きるか | 注意 |
|---|---|---|
| 右上「操作方法」 | PC／スマホの操作一覧とURL共有の説明が開きます（Esc や × で閉じる） | — |
| 右上の＋−／ホイール／ピンチ | 最大 z18 まで寄れます。ヘッダーの「z 18.0」が琥珀色になったら拡大表示です | z17 超は公式想定を引き伸ばして表示するだけで、精度は上がりません |
| 「津波の発生パターンを選ぶ」 | 内閣府の津波ケース①〜⑪（大すべり域＝震源域の位置）を選ぶと、その市区町村の**そのケースの最大津波高（公表値）**が津波高に入り、地図の青塗りが変わります | 候補は公式ケースだけです。選ぶと地図に**赤い範囲（震源域＝大すべり域・超大すべり域の概略）**が出ます。震源の一点ではなく範囲で、公式の区域名に対応する目安です（公式図の正確な範囲・断層線・破壊開始点ではありません）。複数区域のケース⑧〜⑪は番号付きラベルで区別します。「震源域と市区町村を一画面に」で両方が入る画角に戻れます |
| 「参考: 揺れの強さ（震度）を選ぶ」 | 気象庁の震度階級の解説（体感・屋内・屋外）を表示します | **地図の浸水表示は変わりません。** 震度から浸水深は計算していません（津波高は上の発生パターンや津波の高さで扱います） |

### パネルの操作

| 部品 | ラベル（画面表記） | 動き |
|---|---|---|
| セレクト | 「都道府県」「市区町村」 | 南海トラフ想定の対象または海岸線を持つ市区町村だけが並びます。都道府県を「すべての都道府県」にすると全件（県名付き）が並びます |
| 検索 | 「市区町村名で検索（部分一致・例: 高知）」 | 入力した文字を含む市区町村に絞り込みます。候補が1件なら Enter で選択 |

| スライダー | 「津波の高さ（T.P.基準）」 | 0〜35 m を 0.1 m 刻みで設定。動かすとプリセットは「手動」になります |
| プリセット | 「2025 最大」「2025 平均」「2012 最大」「手動」 | 選択中の市区町村の公表値を一発設定。ボタンの下に値が出ます。「データなし」のボタンは押せません |
| ボタン | 「視点リセット」 | 初期視点へ戻す |

| チェック | 「建物（PLATEAU）を表示」 | 建物の箱を表示（既定ON、対応都市のみ・ズーム16以上） |
| チェック | 「写真地図に切替（地理院 全国最新写真）」 | 下地を淡色地図から航空写真に切替 |
| チェック | 「地形の陰影を表示（重い場合はオフ）」 | 地形の陰影を表示（既定ON）。動きが重い時はオフ |

## 7. 津波の高さの決め方

### プリセットの意味

| プリセット | 意味（出典） |
|---|---|
| 2025 最大 | 内閣府「南海トラフ巨大地震モデル検討会」（2025年）市町村別一覧表の**最大津波高**。アプリの既定 |
| 2025 平均 | 同一覧表の平均津波高（複数ケースの平均） |
| 2012 最大 | 内閣府 2012 年公表の市町村別一覧表の最大津波高 |
| ケース別 | 「津波の発生パターン」で選んだ内閣府 津波ケース①〜⑪の、その市区町村の最大津波高（2025 一覧表のケース別の値） |
| 手動 | スライダーで任意の高さ（0〜35 m）を指定 |

いずれも**海岸線での値**です。「震度」から津波の高さは決められません（震度は揺れの強さ、津波高は海面の上がり方で、別のものです）。

### T.P.（ティーピー）とは

**東京湾平均海面**（Tokyo Peil）のことで、日本の標高の基準（0 m）です。
本アプリの「津波の高さ」も地図の標高も、すべて T.P. を基準にしています。

## 8. 見え方の読み取り方

| 見えるもの | 意味 |
|---|---|
| **公式想定の色分け**（黄→赤→紫） | 「公式浸水想定」ON のときの色は、重ねるハザードマップ（津波浸水想定）の**浸水深の凡例**です。0.3m未満（薄黄）〜20m以上（紫）。パネルの凡例と同じ色です |
| **青の濃淡**（試算） | 「津波高で試算」ON のとき、設定した津波高よりその土地がどれだけ低いか。**3 m以上低い**＝濃い青、**1 m低い**＝中間、**水際**＝淡い青 |
| 青が**選んだ市区町村の外に出ない** | 試算は選択市区町村のポリゴンの中だけに限定しているためです（隣の市区町村は津波高が違うため） |
| **公式の色が無い場所** | 未公表・未収録の地域。**表示が無い＝安全ではありません** |
| **青い建物** | 建物の足元の標高が津波高以下と判定された建物（対応都市のみ）。灰色は津波高より高い建物 |

## 9. 表示設定の説明

| 設定 | ONにすると | 通信量・重さ |
|---|---|---|
| 公式浸水想定 | 公式の浸水想定が半透明で重なる（既定ON） | タイル1枚ずつ取得。軽い |
| 津波高で試算 | 津波高以下の土地を青く塗る（選択中は市区町村内のみ） | 標高タイルを使用。中程度 |
| 写真地図に切替 | 淡色地図の代わりに航空写真が下地になる | 写真は淡色地図より通信量が多め |
| 建物（PLATEAU）を表示 | 建物を箱で立体表示（対応都市・ズーム16以上） | 拡大時のみ必要な部分だけ取得 |
| 地形の陰影を表示 | 地形の起伏が影で分かりやすくなる | **OFFにすると描画が軽くなります** |

## 10. よくある質問・困ったとき

| 症状・疑問 | 原因と対処 |
|---|---|
| 地図が真っ白 | 通信が途切れているか、ブラウザが古い可能性。再読み込みし、別ブラウザで試す。「このブラウザでは3D地図を表示できません」と出る場合はWebGL2非対応です |
| 市区町村が一覧に無い | 一覧には南海トラフ想定の対象または海岸線を持つ市区町村だけが並びます。内陸の市区町村は選べません |
| 津波高が「データなし」 | 内閣府の一覧表にその市区町村の値がありません。スライダー（手動）で高さを指定してください |
| 公式想定が何も出ない | その地域の津波浸水想定が未公表・未収録か、「公式浸水想定」がOFF。**表示が無い＝安全ではありません** |
| 青い試算が出ない | 「津波高で試算」がOFF（スライダーを動かすと自動ON）。市区町村を選択中はその外は塗られません（未選択なら全国一律で塗られます） |
| 建物が出ない | ズーム16以上まで拡大し、「建物（PLATEAU）を表示」がONか確認。対応していない都市では出ません |
| 黄色いバナーが出た（標高） | 標高タイルに接続できていません。**この状態の試算は信用しないでください**。通信を確認して再読み込み |
| 赤いバナーが出た | データの読込に失敗しています。メッセージに従い、再読み込みしてください |
| 動きが重い・カクつく | 「地形の陰影を表示」をOFF、「建物」をOFF、写真地図をOFF。傾きを浅くしても軽くなります |
| オフラインで使える？ | 使えません。起動時から常にネットワークが必要です |

## 11. スマホでの注意

- **ホーム画面に追加できます**（Safariの共有ボタン → 「ホーム画面に追加」、Androidはメニューの「アプリをインストール」など）。アイコン名は「南海津波3D」です。
- **横向き**にすると、ボトムシートが低くなり地図が広く見えます。
- **ピンチでのページ拡大は無効**です（ピンチは地図の拡大縮小に使われます）。
- データ量の目安: 起動から近所を確認する程度で数MB〜十数MB、写真地図＋建物で広く見回すと数十MB以上になることがあります。

## 12. 用語集

| 用語 | 説明 |
|---|---|
| T.P. | 東京湾平均海面。日本の標高の基準（0 m）。本アプリの高さはすべてこの基準 |
| 市町村別津波高 | 内閣府「南海トラフ巨大地震モデル検討会」が公表した、市区町村ごとの海岸線での最大津波高（2025年・2012年） |
| 重ねるハザードマップ | 国土交通省ハザードマップポータルサイトの機能。都道府県が公表した津波浸水想定を国が統合したもの |
| 標高タイル | 国土地理院が配信する標高データ（DEM10B、約10 mメッシュ）。これで3D地形を作っています |
| color-relief | 標高に応じて色を付ける地図の描画方式。試算では「津波高以下＝青、それ以上＝透明」にしています |
| PLATEAU（プラトー） | 国土交通省が公開している日本の3D都市モデル。建物を「高さ付きの箱」で表示 |
| PMTiles | 大きな地図データを1つのファイルにまとめ、必要な部分だけを取り出せる形式。建物データに使用 |
| ズーム | 地図の拡大レベル。数字が大きいほど拡大 |
| WebGL2 | ブラウザで3D描画を行う仕組み。非対応だと本アプリは動きません |
